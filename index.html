Sudais Studio Uploader

A private tool for uploading my own videos to my own YouTube channels.

Sudais Studio Uploader uploads videos created by its owner to the owner's YouTube channels, Global Info TV and Global Conflict TV, using YouTube API Services. Before each upload the owner chooses the title, description, tags, thumbnail, playlist, publish time and visibility (public, private or unlisted).

The tool is not offered to the public and has a single user: its owner.
