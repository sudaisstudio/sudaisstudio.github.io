Sudais Studio Uploader

A private tool for publishing my own videos to my own accounts.

Sudais Studio Uploader publishes videos created by its owner to the owner’s own YouTube channels, Facebook Pages, Instagram accounts and TikTok accounts, using the official YouTube API Services, Meta Graph API and TikTok Content Posting API. Before each upload the owner chooses the title or caption, description, thumbnail or cover, publish time and visibility.

It can also show the owner the statistics of those same accounts. The tool is not offered to the public and has a single user: its owner.
